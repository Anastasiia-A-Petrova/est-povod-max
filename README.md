## 🇷🇺 О проекте

**ЕСТЬ ПОВОД!** — приложение с календарём праздников и личных дат, которое помогает не забывать важные события и быстро найти или создать поздравительную открытку.

Приложение работает как **MAX Mini App** и включает:

- 📅 календарь праздников и памятных дат;
- 🎉 светские и другие календарные события;
- ☦️ информацию православного календаря;
- 🎂 личные даты — дни рождения, годовщины и другие события;
- 💌 поиск готовых поздравительных открыток;
- 🎨 создание собственных открыток;
- 🖼️ сохранение и отправку открыток как изображений;
- 📱 адаптивный интерфейс для телефона и компьютера.

## ✨ Возможности

### Календарь

Приложение объединяет несколько типов поводов:

- все события;
- светские праздники;
- православные события;
- личные даты пользователя.

Личные события сохраняются локально в браузере с помощью `localStorage`.

### Готовые открытки

Для выбранного праздника приложение может искать уже готовые поздравительные открытки через несколько внешних источников.

### Создание открытки

Пользователь может создать собственную открытку, выбрать оформление, текст и другие доступные параметры, а затем сохранить результат как изображение.

Для формирования изображения используется `html-to-image`.

### MAX

Приложение адаптировано для запуска внутри MAX Mini App и использует MAX Web App SDK.

## 🔌 Архитектура

Приложение состоит из frontend и backend.

```text
                    ПОЛЬЗОВАТЕЛЬ
                         │
                         ▼
                 MAX Mini App
                         │
                         ▼
               React + Vite frontend
                         │
              ┌──────────┴──────────┐
              │                     │
              ▼                     ▼
        Календарные API       Layero backend
                                    │
                         ┌──────────┴──────────┐
                         │                     │
                         ▼                     ▼
                    Azbyka API         Поиск открыток
                                             │
                                  ┌──────────┼──────────┐
                                  ▼          ▼          ▼
                               Yandex   Otkritki   Livecard
```

Frontend отвечает за интерфейс, календарь, личные даты и создание открыток.

Backend используется для запросов, которые не должны выполняться напрямую из браузера, в том числе для получения данных православного календаря и поиска готовых открыток.

  "service": "azbyka"

## 🔗 API

### Проверка backend

```http
GET /api/health
```

Проверяет, запущен ли сервер.

### Православный календарь

```http
GET /api/orthodox?date=YYYY-MM-DD
```

Пример:

```text
https://est-povod-max-api.layero.app/api/orthodox?date=2026-10-09
```

### Готовые открытки

```http
POST /api/ready-cards
Content-Type: application/json
```

Пример тела запроса:

```json
{
  "title": "День рождения"
}
```

`title` содержит название праздника или повода, для которого выполняется поиск.

### Прокси изображений

Backend также предоставляет прокси для изображений, которые используются приложением при работе с внешними источниками.

## 📡 Внешние источники

Приложение использует несколько внешних источников данных:

| Источник | Использование |
|---|---|
| Nager.Date | Государственные праздники |
| Kuzyak Calendar API | Дополнительные календарные данные |
| Азбука веры | Православный календарь |
| Wikipedia API | Информация о праздниках |
| Yandex Images | Поиск изображений и готовых открыток |
| OtkritkiOnline | Готовые поздравительные открытки |
| Livecard | Дополнительный источник открыток |

Не все внешние источники предоставляют официальные API.

Поиск готовых открыток частично основан на обработке HTML внешних сайтов. Поэтому изменение структуры сайта, ограничение доступа или антибот-защита стороннего сервиса могут повлиять на результаты поиска.

## 🔐 Переменные окружения

Backend использует переменные окружения для конфиденциальных данных.

Основные переменные:

```env
AZBYKA_EMAIL=your_email
AZBYKA_PASSWORD=your_password
PORT=3000
```

`PORT` может задаваться хостингом автоматически.

### Безопасность

- не публиковать реальные пароли и токены;
- не добавлять `.env` в Git;
- не размещать серверные секреты во frontend-коде;
- при случайной публикации секрета сразу заменить его.

## 🚀 Локальный запуск

### Требования

- Node.js
- npm
- Git
- интернет-соединение для внешних API

### 1. Клонирование

```bash
git clone https://github.com/Anastasiia-A-Petrova/est-povod-max.git
cd est-povod-max
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка `.env`

Создай файл `.env` в корне проекта:

```env
AZBYKA_EMAIL=your_email
AZBYKA_PASSWORD=your_password
```

Не добавляй настоящий `.env` в GitHub.

### 4. Запуск frontend

```bash
npm run dev
```

Обычно приложение будет доступно по адресу:

```text
http://localhost:5173
```

### 5. Запуск backend

В отдельном окне терминала:

```bash
npm start
```

Локальный backend использует порт, указанный в `PORT`, либо порт по умолчанию, заданный сервером.

Проверка:

```text
http://localhost:3000/api/health
```

## 💾 Хранение личных дат

Личные даты пользователя сохраняются в `localStorage`.

Это означает:

- данные хранятся в конкретном браузере;
- они не синхронизируются между устройствами;
- очистка данных браузера может удалить сохранённые даты;
- серверная база данных для личного календаря не используется.
